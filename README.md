# *Skolcoffee*
# *Бизнес-проект*: 
Открытие кофейни на территории бизнес-центра в Сколково.
# *Состав группы*: 
Овсепян Анна(github: aovsepyan)

Чертихина Варвара(github: @varcher)
# *Идея компании*:
Возможность окунуться в инновационную атмосферу и попробовать авторские позиции из нашего меню. Компания создается специально для сотрудников и резидентов инновационного центра Сколково. В нашем ассортименте оригинальные напитки и сытные перекусы, они отлично подойдут для повышения работоспособности и настроения, а атмосфера заведения в инновационном стиле соответствует передовым технологиям.
